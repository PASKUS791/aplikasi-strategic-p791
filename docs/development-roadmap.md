# Roadmap Pengembangan

## Tahap 0 - Setup Publik

Target:

- Repo GitHub dibuat dengan nama display "Aplikasi Strategic P791".
- Halaman GitHub Pages aktif.
- Halaman status menampilkan coming soon, jam berjalan WIB, dan count-up sejak meeting.
- README dan workflow kerja tim tersedia.

Status lokal: selesai disiapkan di repo ini.

## Tahap 1 - MVP Web Internal

Target:

- Login anggota.
- Role dasar: admin, PTI, scouting, anggota.
- Dashboard status aplikasi.
- Modul data publik/non-sensitif.
- Struktur data marker dan strategi.
- Admin panel sederhana untuk tambah/edit data.

Output:

- Aplikasi web internal yang bisa diuji PTI.
- Data dummy untuk marker dan strategi.
- Checklist beta test.

## Tahap 2 - Data Scouting dan Validasi

Target:

- Template input data scouting.
- Alur status data: draft, review, approved, published.
- Riwayat perubahan data.
- Catatan reviewer.
- Jadwal meeting validasi.

Output:

- PTI bisa upload data.
- Scouting bisa mengirim update.
- Data baru tidak langsung tampil sebelum approval.

## Tahap 3 - Keamanan dan Lisensi

Target:

- Registrasi device.
- Batas maksimal 3 device per pengguna.
- Approval tambah/ganti/cabut device.
- Watermark personal.
- Audit login.
- Deteksi sesi mencurigakan.

Output:

- Akses tidak hanya bergantung pada username/password.
- Pengelola punya catatan aktivitas user dan device.

## Tahap 4 - Beta Test

Target:

- PTI dan scouting menjalankan uji coba.
- Kumpulkan bug, masukan UX, dan masalah data.
- Perbaiki keamanan dasar.
- Siapkan materi pengumuman.

Output:

- Release candidate untuk anggota terbatas.

## Tahap 5 - Rilis Bertahap

Target:

- Aktivasi anggota berbayar secara bertahap.
- Monitoring penggunaan.
- Promosi demo/video.
- Penentuan prioritas fitur lanjutan.

Output:

- Rilis awal untuk anggota PASKUS791.

## Tahap 6 - Fitur Lanjutan

Target:

- Overlay map.
- Dukungan mobile/desktop app jika benar-benar diperlukan.
- Sistem subscription/payment.
- Integrasi domain `strategic.paskus791.cloud`.
- Backend real-time yang tidak bergantung pada repo publik.
